# Natural Philosophy with Uchchhash

Free physics learning platform — SSC, HSC and advanced courses with chapter videos and free resources.

## Stack

Next.js 16 (App Router) · TypeScript · Tailwind CSS v4 · GSAP · Prisma + Supabase PostgreSQL · Supabase Auth (admin only) · Cloudinary

## Local setup (Windows)

```powershell
npm install
copy .env.example .env.local   # then fill in values — never commit .env.local
npm run dev
```

Open http://localhost:3000

## Scripts

- `npm run dev` — dev server
- `npm run build` — production build
- `npm run lint` — ESLint
- `npm run format` / `npm run format:check` — Prettier
